Tipe nilai

  • Teks memakai tanda kutip ganda. "29" adalah teks, sedangkan 29 adalah angka. Huruf besar dan kecil berpengaruh pada nama field dan pencocokan teks. Pakai \" jika tanda kutip merupakan bagian dari teks yang dicari.
  • Angka bisa ditulis sebagai integer, desimal, atau notasi eksponen, misalnya 200, 100.5, dan 1e3. Integer di luar rentang aman JavaScript membutuhkan browser yang menyediakan token angka asli.
  • Boolean dan null ditulis tanpa kutip, misalnya data.ok = true, data.ok = false, dan data.result = null. Field yang hilang tidak cocok dengan kondisi apa pun. Gunakan null untuk field yang ada dengan nilai null.

Field dan path

  • Metadata log. Gunakan field seperti uuid, requestTime, endTimeRequest, endpoint, method, responseCode, responseTimeMs, httpStatus, dan exception jika tersedia. Durasi dihitung dalam milidetik.
  • Field bertingkat. Gunakan titik untuk masuk ke objek. Nama field boleh berisi huruf, angka, garis bawah, atau tanda hubung, dengan huruf atau garis bawah di awal.
  • Array. Gunakan indeks mulai dari [0], misalnya headers.x-device-no[0] = "13" atau data.data[0].OutletID = "47136".
  • Wildcard array. Gunakan [*] supaya kondisi cocok jika minimal satu item memenuhi filter, misalnya params.data.Details_Item[*].TransactionID = "29". Setiap kondisi dalam and bisa cocok dengan item yang berbeda.
  • Body. Mulai dari params untuk body request atau data untuk body response. Tambahkan satu segmen path untuk setiap level objek. Untuk body teks atau JSON terpotong, cari teksnya langsung, misalnya data contains "[TRUNCATED".

Contoh investigasi

  • Request POST dengan HTTP 4xx atau 5xx method = "POST" and responseCode >= 400
  • Endpoint options lebih dari satu detik endpoint contains "/app/options" and responseTimeMs > 1000
  • Upload arsip gagal responseCode = "FAILED" and params.objectKey contains "NetworkLog"
  • ID transaksi di objek data dalam Params / body params.data.TransactionID = "29"
  • ID transaksi di objek data dalam Response data data.data.TransactionID = "29"
  • ID transaksi langsung di root Response data data.TransactionID = "29"
  • ID pada item mana pun yang memuat teks 29 params.data.Details_Item[*].TransactionID contains "29"
  • AutoClearing sebagai string di Params / body params.data.AutoClearing = "true"
  • AutoClearing sebagai boolean di Params / body params.data.AutoClearing = true
  • AutoClearing sebagai string di objek data dalam Response data data.data.AutoClearing = "true"
  • Potongan teks JSON mentah params contains "\"AutoClearing\":\"true\"". Pencocokan ini mengikuti spasi pada teks asli, jadi gunakan query berdasarkan field jika memungkinkan.
